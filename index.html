Project overview

Our calculator adds and subtracts two 16-bit numbers, A and B. It is built in CircuitVerse from sixteen one-bit full adders. The carry-out of each adder goes into the carry-in of the next one, starting at bit 0 (the rightmost bit) and ending at bit 15.

A mode switch called M picks the operation. Set M = 0 to add. Set M = 1 to subtract. When M = 1, the circuit flips every bit of B and adds 1, which gives A - B.

The circuit shows a 16-bit result and a carry-out called Cout. In add mode, Cout = 1 means the sum is too big for 16 bits (a carry). In subtract mode, Cout = 1 means no borrow (A is greater than or equal to B), and Cout = 0 means there was a borrow (A is less than B).

How to use the calculator

Steps

  1. Click Open in CircuitVerse and select Launch Simulator if it appears.
  2. Set the 16-bit input A.
  3. Set the 16-bit input B.
  4. Set the mode M: 0 for addition, 1 for subtraction.
  5. Read the 16-bit result and Cout.

Reading carry and borrow

ModeCout = 1Cout = 0
M = 0 (add)CarryNo carry
M = 1 (subtract)No borrowBorrow

Remember: in subtract mode the meaning of Cout is reversed. Cout = 0 means A is less than B.

The circuit

Worked examples

Example 1: addition, 00FF + 0001

  • Mode M = 0 (add)
  • A 0000 0000 1111 1111 (hex 00FF, decimal 255)
  • B 0000 0000 0000 0001 (hex 0001, decimal 1)
  • Expected 0100, carry 0
  • Observed 0100, Cout = 0
  • Meaning 255 + 1 = 256. It fits in 16 bits, so there is no carry.

Example 2: subtraction, 0003 - 0005

  • Mode M = 1 (subtract)
  • A 0000 0000 0000 0011 (hex 0003, decimal 3)
  • B 0000 0000 0000 0101 (hex 0005, decimal 5)
  • Expected FFFE, borrow 1
  • Observed FFFE, Cout = 0, so there is a borrow
  • Meaning FFFE is 65,534. 65,534 - 65,536 = -2, which is 3 - 5. The borrow shows that A is less than B.
